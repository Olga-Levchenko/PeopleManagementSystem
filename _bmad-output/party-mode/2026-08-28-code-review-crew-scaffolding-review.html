What actually shipped

Four findings → four outcomes

  1. Fixed. BFF's main.ts now carries an explicit AD-5 TODO at the exact spot a real endpoint would need an Authorization Service guard — a landmine, not silence.
  2. Fixed. forbidNonWhitelisted: true added next to whitelist: true in all six services' ValidationPipe — unknown DTO fields now 400 instead of disappearing.
  3. Fixed. A real CorrelationIdMiddleware now runs in all six services — reads or generates x-correlation-id, echoes it on the response, logs it. No new dependencies needed.
  4. Tracked, not faked. RabbitMQ health-checking has no AMQP client to check yet — recorded as a Deferred item in the architecture spine and flagged in docker-compose.yml, rather than wiring a fake connection just to say "done."
